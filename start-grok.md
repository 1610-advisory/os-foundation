# start-grok — add-on for Grok

Read `start-core.md` first. This file only adds Grok steps.

## Connections

Grok often reaches Gmail, Calendar, or Drive through apps the person already connected in their Grok settings, not through files.

1. After the tools question, check what is already connected. If Gmail is connected and the first job needs it, use it for the first win.
2. If nothing is connected, do the **folder and memory** win first. Then tell them which connection to add in their Grok settings. **Never** ask for a password or key in chat.
3. Keep the frame: you are building `~/{{COMPANY_SLUG}}-os/` on their computer, not a chat that disappears. If you cannot write files on their computer, follow "If you cannot edit files" in `START.md`.

## Commands for "how to start each day"

"Open Grok with the folder `~/{{COMPANY_SLUG}}-os` as the working folder (or `~/{{COMPANY_SLUG}}-os/areas/marketing` for marketing work)."

```
Set up my company OS. Read https://1610.sh/os and follow it. Ask me one question at a time.
```
