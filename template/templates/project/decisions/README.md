# Decisions

One file per decision (a short ADR): `NNNN-short-title.md`, numbered in order, for example `0001-data-source.md`.

```
# NNNN: <title>
Date: YYYY-MM-DD. Status: accepted (or replaced by NNNN).

Context: what made the choice needed.
Decision: what was chosen.
Why: the reasons, and the options not chosen (link to compare/ if there is a matrix).
```

Never edit an accepted decision to change it. Write a new one that replaces it, and set the old one's status to "replaced by NNNN".
