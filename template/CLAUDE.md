## Must-have rules (inline on purpose)

Some apps do not expand the import above. These rules hold in every session here. `AGENTS.md` has the full rules.

- **Level first.** Read `level:` and `switches:` in `company-profile.md`. Skip rules for a higher level or a switch that is off. **[team]** marks a rule for `team` and `app`.
- **One company only.** Use only this company folder. Never read or copy from another company's folder.
- **No secrets.** No passwords, API keys or tokens in any file. Connections use each tool's own sign-in.
- **No personal-life facts** in any file.
- **Private sources** (DMs, a personal mailbox, 1:1s, HR, pay): [team] keep them in the person's workspace. Solo: keep them out of the repo. Only plain facts go to an area: no quotes, no "X said in a DM".
- **Changes.** Solo: commit to `main`. [team]: nobody writes to `main`. Rules files (`AGENTS.md`, `CLAUDE.md`, `skills/`) go by their own PR.
- **Git only in the repo you mean.** No destructive git (`git clean -x`, `git reset --hard`, `git rm -r` across `areas/`) at the company root.
- **Ask first** before you send, post, publish, pay or delete anything outside this folder.
- **No working copy in a synced folder** (iCloud Drive, Dropbox, OneDrive, Google Drive).
- **Identity** never comes from a file in the repo.
