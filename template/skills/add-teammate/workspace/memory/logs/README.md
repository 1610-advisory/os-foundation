# Logs

One file per day: `YYYY-MM-DD-<person>.md`. `<person>` is the person's slug.

- Write what was done in this workspace and what is open.
- Short lines. A summary, not a transcript.
- Never write the content of a private source. Write "replied to a customer email", not what the email said.
- Work in an area gets logged in that area's `memory/logs/`, not here.
