## Must-have rules (inline on purpose)

Some apps do not expand the import above. These rules hold in every session here. `AGENTS.md` has the full rules.

- **Company skills are in `../../skills/`.** If missing, read them from the company repo on the host.
- **Level first.** Read `level:` and `switches:` in `../../company-profile.md`. Skip rules for a higher level or a switch that is off. **[team]** marks a rule for `team` and `app`.
- **One company only.** Never read or copy from another company's folder.
- **No secrets** in any file. **No personal-life facts** in any file.
- **Private sources:** [team] keep them in the person's workspace. Solo: keep them out of the repo. Only plain facts go here.
- **Leadership and access material** (OS build, systems and access, connections, org and billing, leadership meetings) goes in `areas/admin/` only, never the shared root.
- **Sharing wider** (another area, the company root) only when the person asks: say who will read it, wait for a clear yes.
- **Changes.** Solo: commit to `main`. [team]: nobody writes to `main`. Rules files go by their own PR. Never type `/approve` or `/override` yourself.
- **Git only in this repo.** **Ask first** before you send, post, publish, pay or delete anything outside this folder.
- **No working copy in a synced folder.** **Identity** never comes from a file in the repo.
- **Sharing up:** company facts and memory go to the root (`../../`) only when a person asks.
