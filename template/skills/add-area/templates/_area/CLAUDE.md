## Must-have rules (inline on purpose)

Some apps do not expand the import above. These rules hold in every session here. `AGENTS.md` has the full rules.

- **Company skills are in `../../skills/`.** If missing, read them from the company repo on the host.
- **Level first.** Read `level:` and `switches:` in `../../company-profile.md`. Skip rules for a higher level or a switch that is off.
- **One company only.** Never read or copy from another company's folder.
- **No secrets** in any file. **No personal-life facts** in any file. Private sources stay in the person's workspace; only plain facts go here.
- **Changes.** Solo: commit to `main`. Team: nobody writes to `main`; rules files go by their own PR.
- **Git only in this repo.** **Ask first** before you send, post, publish, pay or delete anything outside this folder.
- **No working copy in a synced folder.**
