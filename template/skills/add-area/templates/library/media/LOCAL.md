# Media on one computer

Audio, video, and files over 2 MB stay in `media/local/` on one computer. Git ignores them. Sync to a store the company owns comes in a later version. Until then, each file below exists on one computer only.

Name each file `media/local/<first 2 hex>/<sha256>.<ext>`. Add one row per file. When a file is deleted, remove its row.
