# SOP: close the register

1. Count the drawer. Write the total on the slip.
2. Match card slips to the batch.
3. Bag the cash. Drop it in the safe.
4. Lock the side door.
5. Text the on-call lead that the shop is closed.

If the count is off by more than $20, leave a note for the bookkeeper. Do not adjust the slip to force a match.
